**AI Data Analysis Assistant 📊**

An interactive data analysis web application built using Python and Streamlit. It helps users explore CSV datasets, understand data patterns, visualize information, and generate AI-powered insights.

**✨ Features**

- **Dataset Overview:** View the number of rows, columns, and dataset information.
- **Column Analysis:** Explore column names, data types, and missing values.
- **Data Quality Checks:** Identify missing values and potential data-quality issues.
- **Statistical Analysis:** View numerical summaries, averages, minimums, and maximums.
- **Category Analysis:** Discover unique categories and frequently occurring values.
- **Data Visualization:** Generate graphs to understand data distributions and relationships.
- **Correlation Analysis:** Explore relationships between numerical variables.
- **AI Assistant:** Ask questions about your dataset and receive AI-powered explanations.
- **Download Options:** Download datasets and analysis reports.

**🛠️ Technologies Used**

- Python
- Pandas
- Matplotlib
- Streamlit
- Google Gemini API

**🚀 How to Run the Project**

1. Clone this repository:
   
   git clone https://github.com/Killites/AI-Data-Analysis-Assistant.git

2. Open the project folder:
   
   cd AI-Data-Analysis-Assistant

3. Install the required packages:
   
   pip install -r requirements.txt

4. Create a ".env" file and add your Gemini API key:
   
   GEMINI_API_KEY=your_api_key_here

5. Run the application:
   
   streamlit run app.py

**🎯 Project Goal**

The goal of this project is to make initial data exploration easier by combining traditional data analysis techniques with AI-powered assistance.
